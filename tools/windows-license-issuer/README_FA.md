# ابزار ویندوزی صدور لایسنس آفلاین انبارین پرو

## قابلیت‌ها
- ساخت جفت‌کلید RSA-3072؛ کلید خصوصی با رمز عبور محافظت می‌شود.
- صدور فایل اختصاصی `.anblic` با امضای دیجیتال RSA-SHA256.
- درج نام مشتری، شناسه قرارداد، پلن، تاریخ انقضا و شناسه دستگاه.
- هر لایسنس برای یک شناسه دستگاه صادر می‌شود (`maxDevices=1`).
- انتقال دستگاه با صدور لایسنس جدید برای شناسه دستگاه جدید و تأیید مدیر انجام می‌شود.

## اجرای برنامه
1. روی ویندوز Python 3.11 یا جدیدتر نصب کنید.
2. فایل `build-windows.bat` را اجرا کنید.
3. فایل نهایی در `dist\AnbarinLicenseIssuer.exe` ساخته می‌شود.
4. ابزار را اجرا کنید و «ایجاد کلیدهای امضای من» را فقط یک‌بار بزنید.
5. پوشه کلیدها را در محل امن نگهداری و از آن نسخه پشتیبان رمزگذاری‌شده تهیه کنید.
6. برای هر مشتری شناسه دستگاه را دریافت کنید، مشخصات را وارد و فایل لایسنس را صادر کنید.

## امنیت کلیدها
- `anbarin-license-private.pem` محرمانه است و هرگز نباید داخل پروژه اندروید، APK، GitHub یا برای مشتری ارسال شود.
- `anbarin-license-public.pem` کلید عمومی است؛ فقط همین کلید برای اعتبارسنجی در برنامه مشتری استفاده می‌شود.
- اگر کلید خصوصی گم شود، صدور لایسنس جدید با همان هویت امضا ممکن نخواهد بود.
- اگر کلید خصوصی افشا شود، باید کلید جدید بسازید و نسخه برنامه را به کلید عمومی جدید ارتقا دهید.

## انتقال دستگاه
این ابزار عمداً لایسنس را به یک Device ID متصل می‌کند. برای انتقال:
1. از مشتری Device ID جدید را دریافت کنید.
2. درخواست و مالکیت مشتری را بررسی کنید.
3. یک لایسنس جدید برای همان مشتری و Device ID جدید صادر کنید.
4. از مشتری بخواهید لایسنس جدید را فعال کند. لایسنس قبلی روی دستگاه جدید معتبر نیست.

## وضعیت ادغام با اپلیکیشن
این بسته ابزار صدور را آماده می‌کند، اما هنوز اعتبارسنجی امضای RS256 و دریافت/نمایش Device ID در خود اپلیکیشن جایگزین جریان قدیمی نشده است. تا تکمیل گام ادغام اپ، فایل‌های `.anblic` در نسخه فعلی برنامه فعال نمی‌شوند. این تفکیک عمدی است تا قفل‌شدن مشتریان فعلی یا حذف سازگاری قبلی رخ ندهد.
